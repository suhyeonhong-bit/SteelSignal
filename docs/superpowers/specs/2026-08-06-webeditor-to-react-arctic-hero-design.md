# WebEditor 편집본의 실제 북극 대시보드 반영 설계

작성일: 2026-08-06  
상태: 사용자 설계 승인 완료

## 1. 목적

WebEditor에서 사용자가 수정한 북극 에너지 연구 대시보드의 상단 디자인을
실제 React/Vinext 대시보드와 재편집 가능한 단일 HTML 산출물에 함께
반영한다. 공개 데이터 자동 갱신, 연구 섹션, `/steel/` 분리 페이지와 배포
구조는 그대로 유지한다.

## 2. 반영 범위

사용자가 직접 바꾼 다음 시각·문구 요소를 반응형 CSS로 옮긴다.

- 내비게이션 링크: 검정 계열 색상과 Pretendard 우선 글꼴
- 히어로 배경: `#f4f6f8`
- 히어로 제목: 검정 본문, `결정` 강조색 `#ef4444`
- 히어로 정렬: WebEditor의 데스크톱 이동량을 유동 여백으로 변환
  - 키커 최대 16px
  - 제목 최대 60px
  - 설명 최대 105px
  - 출처 최대 35px
- 히어로 설명: 사용자가 수정한 세 문장과 데스크톱 3줄 구성

다음 항목은 편집기 또는 우발적 드래그 산출물로 보고 반영하지 않는다.

- `data-editor-slide`, `data-webeditor-slide-vars`
- `webeditor-html-sizing`, `webeditor-canvas-size` 메타데이터
- 1920×1080 고정 인쇄 규칙
- 요소의 고정 `width`, `height`, `transform: matrix(...)`
- 연구 카드의 약 1.2px 수직 이동

## 3. 반응형 변환

React 마크업에는 히어로 설명의 각 문장을 `span`으로 구분한다. 데스크톱에서는
각 `span`을 블록으로 표시해 WebEditor의 세 줄 구성을 재현하고, 760px 이하에서는
인라인으로 바꾸고 문장 사이에 공백을 넣어 화면 폭에 따라 자연스럽게 줄바꿈한다.

데스크톱 이동량은 뷰포트 기반 `clamp()` 여백으로 구현한다. 고정 좌표를 쓰지
않으므로 1180px 콘텐츠 폭 안에서 사용자의 구도를 보존하면서 중간 화면에서도
가로 스크롤이 생기지 않는다. 760px 이하에서는 모든 추가 좌측 여백을 0으로
되돌리고 제목 폭 제한을 해제한다.

## 4. 파일별 책임

- `app/components/ArcticResearchDashboard.tsx`
  - 수정된 히어로 설명 문구와 문장 단위 마크업 제공
- `app/arctic.css`
  - 운영 화면의 내비게이션·히어로 색상, 글꼴, 배경, 반응형 정렬 제공
- `webeditor/arctic-dashboard.html`
  - 같은 문구와 시각 규칙을 유지하는 다음 편집용 원본 제공
- `tests/arctic-hero-design.test.mjs`
  - React, CSS, WebEditor 산출물이 동일한 사용자 의도를 유지하는지 검증

## 5. 유지되는 계약

- EIA·OFAC·EU·NSIDC 공개 데이터 로딩과 폴백은 변경하지 않는다.
- `data-bind`, `data-region`, `#arctic-runtime`, `#arctic-fallback`을 보존한다.
- 패권 지수의 2025·2027·2033 상호작용을 보존한다.
- `/steel/` 페이지와 링크를 보존한다.
- API 키나 환경변수를 클라이언트 파일에 넣지 않는다.
- 내비게이션, 버튼, 링크의 키보드 접근성과 포커스 표시를 보존한다.

## 6. 검증

자동 검증은 다음을 확인한다.

- React와 WebEditor HTML에 수정된 세 문장이 모두 존재한다.
- 히어로 설명이 문장 단위 `span` 구조를 사용한다.
- 운영 CSS와 단일 HTML 모두 `#ef4444`, `#f4f6f8`, Pretendard 내비게이션,
  반응형 `clamp()` 여백과 모바일 초기화 규칙을 포함한다.
- WebEditor 전용 슬라이드 메타데이터가 저장소 원본에 들어오지 않는다.
- 전체 테스트, 린트, Vinext 빌드, Vercel용 정적 빌드와 Pages 빌드가 통과한다.

브라우저 검증은 데스크톱과 모바일에서 제목·설명이 겹치지 않고, 내비게이션,
패권 지수, 자동 데이터 상태가 기존처럼 동작하는지 확인한다.

## 7. 완료 기준

1. 실제 루트 대시보드가 WebEditor에서 확정한 상단 디자인을 반응형으로 표시한다.
2. 다음 편집용 단일 HTML도 같은 디자인과 문구를 가진다.
3. 자동 갱신과 모든 연구 섹션이 회귀 없이 유지된다.
4. Vercel용 빌드 산출물에서 변경된 히어로가 확인된다.
